OtoSINT

OtoSINT is a modular OSINT reconnaissance framework developed to streamline passive reconnaissance workflows commonly used in bug bounty and attack surface discovery. The project aggregates subdomains from multiple sources, normalizes the results, and removes duplicates to produce a cleaner dataset for further analysis.

Lessons Learned

During development, I encountered reliability issues with legacy enumeration tools and adapted the framework to use a more stable passive reconnaissance pipeline. The project also highlighted the importance of data normalization, result deduplication, and graceful error handling when aggregating information from multiple OSINT sources.
