## Vulnerability Assessment & Penetration Testing

Two web application security assessments completed as part of different cybersecurity bootcamps.

The projects involved reconnaissance, vulnerability discovery, manual validation, proof-of-concept testing, impact assessment, and security reporting.

### Projects

- JerseySekaT Web Application Assessment

The assessments covered issues including:

- Authentication and authorization weaknesses
- IDOR
- Business logic flaws
- SQL Injection
- Cross-Site Scripting
- Unrestricted file upload
- Directory listing
- Security misconfiguration
- Information disclosure

Both assessments are documented with their respective reports and selected evidence.
